# Exploratory Data Analysis — лабораторная работа 4

Это учебная лабораторная работа для знакомства с Data Science и погружения в
разведочный анализ данных. В ноутбуке рассматриваются автоматизированные
отчёты `dtale`, `ydata-profiling` и `sweetviz` на данных об успеваемости
учащихся и продажах видеоигр.

## Файлы данных

- `Students.csv` — сведения об учебных результатах и связанных признаках.
- `Video_Games_Sales_as_at_22_Dec_2016.csv` — продажи и оценки видеоигр
  по платформам и регионам.

Ноутбук и оба CSV должны находиться в одной папке.

## Запуск

Откройте `ИАД-РТ-4.ipynb` в Jupyter Notebook или VS Code и выполняйте ячейки
по порядку. Требуются Python, `numpy`, `pandas`, `matplotlib`, `seaborn`,
`scipy`, `dtale`, `ydata-profiling` и `sweetviz`. HTML-отчёты создаются в
папке `reports/`.
